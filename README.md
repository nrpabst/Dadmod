# dadmod

dadmod is a mod for THUG Pro (plain THUG Pro or Kali Mod): custom main menus, menu colors and effects,
graphics options, animations, extra levels and more. It never changes THUG Pro's or Kali's own files.

## Install

1. Download `dadmod.zip` from the newest release on the [Releases](../../releases) page.
2. Close THUG Pro and unzip it into your THUG Pro folder (the one with THUGPro.exe).
3. Open the `dadmod-install` folder and run `Setup.bat`, then pick Install.

Setup.bat also updates dadmod (it checks this page for a newer release, betas included), repairs it, or uninstalls it.
